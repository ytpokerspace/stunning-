# POKÉLLM Browser Game

Open `index.html` in a modern browser or publish the `web/` directory with GitHub Pages.

- Mobile-friendly, high-contrast interface with large controls.
- Three original public starter creature illustrations.
- Solo battle prototype with attack, guard, heal, and special actions.
- Emoji state display; local pass-and-play/remote networking is not implemented here.
- This browser prototype uses a JavaScript rules implementation for standalone play. The Python engine remains the reference implementation.

The Founder’s Pack is private and is deliberately not present in this public repository. No founder names, creature designs, stats, moves, or artwork are included.
